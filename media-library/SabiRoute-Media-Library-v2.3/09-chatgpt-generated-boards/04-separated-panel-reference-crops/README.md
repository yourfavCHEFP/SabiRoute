# CG-029 separated panel references

These 12 files were made by exact rectangular pixel crops from the existing 1536×1024 composite image `CG-029-wide_cinematic_tech_brand_asset_presentation_portf.png`. No generative model was used to create the crops, and no underlying design was redrawn.

## What these are

They are separated **numbered panels** so you can inspect one section at a time. They are not the same thing as extracting every logo, icon, banner, or diagram inside each panel into a clean, independently generated source image. Some panels still contain several mini-designs, UI text, borders, and labels.

## How to use them

- Use `01` for comparing the logo family, not as the final logo export.
- Use `02` and `06` as hero/README art-direction references; do not put the whole mockup on the website as a hero background.
- Use `03` as an icon-selection reference; icons still need individual crops or clean re-exports.
- Use `04` as an architecture illustration reference only; derive exact editable diagrams from verified source code.
- Treat `05` as a mockup. Embedded GitHub statistics and UI are illustrative and must not be published as facts.
- Use `07`, `08`, `10`, and `11` as selection/storyboard boards, not as independent covers, social cards, GIF frames, or presentation slides.
- Treat `09` as a palette/type reference until color values and font choices are approved.
- Treat `12` as illustrative; the panel does not itself prove archive contents.
