## 1. Scope

R6.2 is the first authorised tranche after R6.1 exit. It owns the immutable original, canonical
form, effective request, transformation record, policy application and validation seam. The seam
is fixed by `R6.1-FOUNDATION-CONTRACT.md` §2.2:

| Contract | Landing site |
|---|---|
| I1, I7, I9 | `src/sabiroute/api/completions.py` |
| I2, I3, I4, I8 | `src/sabiroute/request_transform/` |
| I5 | `src/sabiroute/config/validation.py` — Track A protected, ratified by Owner Row B |
| I6 | `request_transform/` + `capabilities.py` read-only |

This contract does **not** invent new budgets, thresholds or ratios. D1 and D2 values are owner-set
and recorded in `D1-D7-OWNER-APPROVAL.md`.

## 3. Contracts and failure mode

| ID | Invariant | On violation |
|---|---|---|
| I1 | The original is deep-frozen; client and provider bytes are equal before/after | Fail to original with `TRANSFORM_ERROR` |
| I2 | Canonical bytes are deterministic, idempotent and never longer than default JSON | Fail to original with `TRANSFORM_ERROR` |
| I3 | One effective request per logical request; monotone shrink | Fail to original |
| I4 | `TransformationRecord` is frozen, scalar-only and carries no message text | Fail to original |
| I5 | Policy is startup-validated; invalid config is a startup failure, not a runtime degrade | Startup failure |
| I6 | Dropping a required capability hard-fails | `CAPABILITY_LOSS`, original restored |
| I7 | Bypass is evaluated once, immutable per request, default-off | Original returned with reason |
| I8 | Effective request is validated under the same caps as I1 | `VALIDATION_FAILURE`, original restored |
| I9 | Fail-to-original on every `Exception`; never catch `BaseException` | `CancelledError` propagates |

Every failure path returns the original messages unchanged. No contract failure becomes a 4xx.

---

## 4. Dark-ship requirement

`OptimizationPolicy.enabled` defaults to `False`. With `enabled=false`, no message is transformed,
no capability check is reached, and the bytes sent to the provider are byte-identical to the
pre-R6 path. This is tested by `test_b5_disabled_policy_sends_byte_identical_messages`.
